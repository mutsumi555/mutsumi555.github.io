# mutsumi555.github.io

考研政治「一页纸」遴选题刷题页 —— 133 道题，纯前端离线可用。

## 访问地址

待 GitHub Pages 部署完成后：**https://mutsumi555.github.io**

## 功能

- 9 大解题方法主题，133 道遴选题
- 单选 / 多选，先选后对，边做边记
- 答题卡、进度条、正确率统计
- 练习进度通过 localStorage 保存在本地浏览器（不上传、不同步，换设备或清缓存会重置）
- **导出 / 导入进度**：首页「数据」区可导出 JSON 备份，换设备时导入恢复
- 自动跟随系统深色 / 浅色模式，手机端适配

## 更新题库

直接替换仓库中的 `index.html` 即可，提交后 Pages 会自动重新部署。
